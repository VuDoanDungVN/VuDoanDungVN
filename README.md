## 自己紹介

日本を拠点に活動する、バックエンド寄りのフルスタックエンジニアです。モバイル・デスクトップ、そしてその裏側にあるシステムまで幅広く担当しています。アイデアを、実際にインストールして使ってもらえるプロダクトに変えることが好きで、モバイルアプリは Flutter と React Native、デスクトップツールは C#、スクリプトの方が向いている課題には Python を使っています。

最近の仕事の多くは **モバイル開発とシステム設計の交差点** にあります。クライアントを作り、その裏側の API を作り、実際のユーザーに使われても両方が耐えられるようにすることです。
